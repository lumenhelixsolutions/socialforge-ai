# Visual Task Interaction Model

Cards are a UI method in SocialForge AI. They are not the whole product.

A card acts as a visible handle for a task, action, draft, campaign item, or scheduled activity. Users can click it, inspect it, move it, approve it, or schedule it.

## Why cards exist

Social media workflows need visible objects.

A visual task card helps answer:

- What is this?
- What is it for?
- What platform does it target?
- Is it approved?
- Is it scheduled?
- What did the AI do?
- What happens next?

## Standard task setup method

Every structured AI task should capture:

1. Objective
2. Output Type
3. Brand / Project
4. Platform / Destination
5. Source Material
6. AI Role
7. Model Lane
8. Constraints
9. Workflow Rule
10. Execution Plan
11. Preview
12. History

## Interaction surfaces

```txt
Workflow Board = state and movement
Calendar       = time and scheduling
Task Card      = clickable visual handle
Inspector      = truth/control panel
Preview Editor = WYSIWYG-ish output surface
Audit History  = trust record
```

## Lifecycle

```txt
Inbox → Idea → Drafting → Needs Review → Approved → Scheduled → Archived
```

Future publishing states:

```txt
Scheduled → Ready to Publish → Published / Failed
```

## Raw creative safety

Raw creative tasks are draft-only.

```txt
Raw creative task
→ raw output
→ promote to safe task
→ review
→ approve
→ schedule
```

Raw outputs cannot be scheduled directly.
