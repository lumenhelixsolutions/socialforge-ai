# First Release Notes

This package is the first public GitHub-ready release of SocialForge AI.

## Identity

```txt
SocialForge AI
```

## Description

```txt
Local-first AI command center for social media planning, content generation, review, and scheduling.
```

## Current scope

This is an experimental draft-first MVP. It supports planning, generation, review, editable previews, local scheduling, and audit history.

It does not publish to live social platforms yet.
