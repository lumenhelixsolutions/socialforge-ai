# Contributing

Most valuable contributions right now:

- Bug reports with clear reproduction steps
- UI/UX feedback
- Accessibility improvements
- Test coverage
- Documentation improvements
- Safer scheduling/publishing architecture
- Local model compatibility improvements

## Rules

1. Keep the app draft-first unless a publishing feature is explicitly scoped.
2. Do not add live posting without approval gates and audit logs.
3. Do not give raw creative cards publishing ability.
4. Every card action should be inspectable and logged.
5. Drag/drop must have a button or menu alternative.
6. Prefer simple, reversible workflows.
7. Add tests for backend behavior.
8. Update docs when changing user-facing behavior.
